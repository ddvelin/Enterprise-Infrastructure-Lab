# Hosted Game Server Labs

This section documents private game servers built and operated in Proxmox virtual machines. Public examples focus on Linux administration, service management, networking, automation, backups, monitoring, and troubleshooting.

No world data, credentials, IP addresses, tunnel hostnames, player information, or copyrighted game/mod files are included.

| Project | Focus |
|---|---|
| [Cozy Zen Minecraft](cozy-zen-minecraft/) | Full Bash automation framework, RCON, backups, restore validation, watchdog, dashboard, and systemd timers |
| [ATM10 Minecraft](atm10-minecraft/) | NeoForge server operations, resource tuning, backups, health monitoring, watchdog recovery, and performance troubleshooting |
| [Palworld](palworld/) | SteamCMD updates, systemd management, RCON, Playit.gg, remote SSH administration, and configuration tuning |
| [Enshrouded](enshrouded/) | Wine/Xvfb hosting, UDP tunneling, Proxmox CPU tuning, systemd service management, and overload troubleshooting |

## Privacy Standard

Every hosted-service project uses sanitized examples. Real secret-bearing configuration remains local and untracked. Public documentation excludes:

- Passwords, tokens, webhooks, and SSH keys
- Internal and public IP addresses
- Playit claim data and public endpoints
- Player names, UUIDs, and whitelist contents
- World saves, backups, and logs
- Copyrighted server packs, game binaries, and mod files
