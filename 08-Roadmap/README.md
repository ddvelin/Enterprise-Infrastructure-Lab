# Homelab Roadmap

The roadmap is organized by operational value and learning goals rather than by adding technology for its own sake.

## Completed Foundation

- [x] Repurpose consumer hardware as a Proxmox host
- [x] Deploy Linux virtual machines and containers
- [x] Configure Proxmox datacenter and node firewall controls
- [x] Add Pi-hole and Unbound DNS
- [x] Add Twingate zero-trust remote administration
- [x] Deploy Proxmox Backup Server
- [x] Add Docker, Portainer, n8n, and Dashy
- [x] Add Pulse and Netdata visibility
- [x] Build Ansible patch-and-verify maintenance automation
- [x] Host and document multiple private game servers
- [x] Build Bash, RCON, systemd, backup, watchdog, and restore workflows
- [x] Sanitize and publish portfolio documentation

## Current Focus

- [ ] Evaluate AMP as the standard platform for casual game hosting
- [ ] Document the complete VM and container inventory
- [ ] Create physical and logical network diagrams
- [ ] Create backup-flow and automation-flow diagrams
- [ ] Add sanitized screenshots to major service pages
- [ ] Build a configuration management database-style inventory

## Next Infrastructure Stage

- [ ] Increase host memory capacity or plan a replacement platform
- [ ] Add a rack-mounted UPS
- [ ] Move the server into a rackmount chassis
- [ ] Add a larger managed switch and patch panel
- [ ] Design dedicated NAS storage with RAID
- [ ] Improve the separation of production, backup, and archive storage
- [ ] Implement OPNsense as the primary firewall platform
- [ ] Introduce VLAN segmentation for infrastructure, users, IoT, cameras, guests, and labs

## Career Lab Expansion

- [ ] Build and document Windows Server Active Directory
- [ ] Configure DNS, DHCP, Group Policy, users, groups, and permissions
- [ ] Add an isolated Kali Linux and vulnerable-target lab
- [ ] Practice Cisco networking and routing scenarios
- [ ] Compare Proxmox with another hypervisor such as Hyper-V or XCP-ng
- [ ] Add PowerShell and Python administration projects

## Long-Term Smart-Home Vision

- [ ] Structured Ethernet cabling throughout a permanent home
- [ ] 10 Gb backbone where it provides practical value
- [ ] Locally managed security cameras
- [ ] Environmental and temperature monitoring
- [ ] Home Assistant or equivalent automation platform
- [ ] Whole-home media, television, and audio integration
- [ ] Local private-cloud storage and services
- [ ] Central monitoring, alerting, and documented recovery procedures

## Success Criteria

The goal is not to collect the largest number of services. The environment should become:

- easier to understand,
- safer to change,
- faster to recover,
- better documented,
- more secure,
- and increasingly representative of infrastructure used by a small organization.
