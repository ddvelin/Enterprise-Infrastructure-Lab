## Screenshot Privacy Checklist

Before adding a screenshot:

- remove or blur internal and public IP addresses,
- remove private DNS names and usernames,
- hide tokens, fingerprints, tunnel endpoints, and QR codes,
- hide player names, UUIDs, and chat content,
- hide backup contents and application data,
- crop unrelated browser tabs and personal notifications,
- and verify image metadata does not expose private information.

Editable Draw.io source files should be retained alongside exported PNG or SVG versions so the diagrams can evolve with the lab.
